# DevVault

A lightweight developer workspace for saving API requests, sending HTTP requests, and reviewing request history.

## Getting started

1. Open the project folder in VS Code.
2. Run it with a local development server (for example, the Live Server extension).
3. Start implementing the JavaScript modules in `src/`.

## Project structure

```text
DevVault/
├── index.html
├── style.css
└── src/
    ├── index.js
    ├── components/
    │   └── app.js
    ├── services/
    ├── utils/
    └── data/
```

The HTML and CSS provide the initial responsive interface. JavaScript functionality is intentionally not implemented yet.
